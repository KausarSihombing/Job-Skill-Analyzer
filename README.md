# 🚀 Job Skill Analyzer

Job Skill Analyzer adalah aplikasi web pencari kerja interaktif yang dirancang khusus untuk para profesional IT. 
Aplikasi ini memungkinkan pengguna untuk mencari, menyaring, dan menemukan lowongan pekerjaan dari perusahaan lokal maupun global berdasarkan posisi, lokasi,
dan keahlian teknis (IT Skills) secara *real-time*.



## ✨ Fitur Utama (Features)

fitur fitur yang terdapat di dalam projek ini:

*   🌍 **Dual Data Source (Lokal & Global):** Fitur saklar interaktif (Single Page Application) yang memungkinkan pengguna berpindah antara database lowongan kerja Indonesia (Lokal) dan Internasional (Global) tanpa perlu memuat ulang halaman (*reload*).
*   🔍 **Fitur Searcing:** Mesin pencari ganda yang memvalidasi input pengguna. Pengguna dapat mencari pekerjaan spesifik berdasarkan Posisi dan Lokasi sekaligus.
*   ⚙️ **Filter untuk mencari di dalam badge:** 
    *   Sistem penyaringan canggih menggunakan checkbox di dalam Pop-up Moda.
    *   **auto refresh:** Pengguna dapat menghapus filter langsung dengan mengeklik tombol (X) pada badge, nanti layar akan memuat ulang data secara otomatis.
*   🔄 **Reset Pintar:** Tombol reset khusus untuk mengosongkan form pencarian dan mengembalikan daftar lowongan ke kondisi awal dengan satu klik.

## 💻 Cara Menjalankan Proyek (How to Run)

Karena proyek ini berjalan murni di sisi *Client-Side* (Frontend), cara menjalankannya sangat mudah:

1. *Clone* repositori ini: `git clone https://github.com/KausarSihombing/Job-Skill-Analyzer.git`
2. Buka folder proyek.
3. Buka file `cari-jobs.html` langsung di *browser* pilihan Anda, ATAU gunakan ekstensi **Live Server** di VS Code untuk pengalaman terbaik.
4. Pastikan Anda memiliki koneksi internet agar data API dan ikon FontAwesome dapat dimuat dengan baik.
